between-order-and-fracture
תרגיל1 – סדר ושבירה / עיצוב באמצעות בינה מלאכותית:

העמוד הוא תעודת זהות בתנועה: הוא מבטא את המתח בין הניסיון שלי להחזיק שגרה ולהיות חלק מהעולם, לבין החוויה שאני נושאת מאז שירות המילואים לאחר השבעה באוקטובר. הגלילה עוברת מסדר לאובדן אחיזה, לשהייה בשבר ולניסיון לפנות מקום לחיים לצדו. הטקסט זמני.
01 / להחזיק
הגריד, הטיפוגרפיה השיטתית וההיררכיה שואבים השראה מהעיצוב השווייצרי וממילר־ברוקמן; שני הצדדים וציר המרכז נשענים על הסימטריה של ווס אנדרסון. הטקסט והשתקפותו מבטאים כפילות בין החוץ לפנים. תוך כדי גלילה, העמודה השמאלית נוטה ויוצאת מסנכרון: המאמץ להחזיק סדר כבר מכיל בתוכו חוסר יציבות.
02 / לאבד אחיזה
מילים נשלפות באקראי מתוך העמודות הנעות ומשאירות בהן חללים. הן מתכנסות במרכז, מתפזרות לקצוות ומשנות פונט, גודל וכיוון, בהשראת הניסויים הטיפוגרפיים של וינגרט, הקריאה המקוטעת אצל קרסון והחספוס של הפאנק. בהמשך, העמוד נשבר לרצועות כמו שידור שמאבד קליטה ונבלע בשחור. השפה עצמה מאבדת את היכולת לארגן את החוויה.
03 / לשהות בשבר
המשפט ״לפעמים גם המילים נגמרות״ נשאר לאורך גלילה ממושכת, ואז יורד ודועך. אחריו מגיע שחור ריק וארוך. ההשהיה נותנת לשבר מקום לפני שמגיע פתרון. שברי מילים דהויים מופיעים בנפרד, אחר כך יחד, ולבסוף נופלים: ניסיון לדבר כשעדיין קשה לייצר משמעות רציפה.
04 / לפנות מקום
הלבן נפתח מצד ימין לשמאל, כפתיחה אל העולם, ובתוכו מופיעה ״אני". בהמשך, מתרחשת הרכבה מחדש מתוך השברים, בקצב שמאפשר לחיים להיכנס.
05 / להמשיך לצד
שני הצדדים חוזרים כ״העולם ואני״. העולם מתקדם בקצב מסודר, אך הצד האישי נע בקצב אחר ונושא שאריות מהשבר. היחסים ביניהם מבטאים ניסיון לחזור לעבודה, ללימודים, למשפחה ולקִרבה, כשהחוויה עדיין נוכחת.
״אתם / אני״ — שתי נקודות מבט
״אתם״ מציג את החוויה דרך טיפוגרפיה ותנועה. ״אני״ משאיר מסך שחור, את שמות השלבים ואת הספירה בלבד. אורך הדרך נשאר זהה, אבל כמעט כל מה שניתן לראות נעלם - פער בין האופן שבו אפשר לתווך חוויה לאחרים לבין השהייה האישית בתוכה.
״להאט לרגע / בקצב שלי״ — אפשרות לוויסות
הכפתור מעניק לצופה בחירה בעוצמת המפגש עם העמוד. הסיפור נשאר, והתנועה נרגעת. הוא מבטא אפשרות למצוא קצב שאפשר להכיל.
״להתחיל מחדש״
החזרה לראש העמוד מאפשרת לעבור שוב את אותו מסלול מתוך מה שכבר נחווה בו. ההתחלה חוזרת, והמשמעות שלה עשויה להשתנות.
